# Inside Battery 0.2.1 — development preview

Newest development preview for Apple Silicon (arm64), macOS 13 or newer.
Intel binaries are not included.

- Lighter High Power purple and a distinct grey empty battery area make the
  charge level visible. Menu-bar fast-forward marks removed.
- Significant-energy results now filter unnamed system coalitions; valid apps
  remain visible and system-only responses show no significant-energy apps.
- Selected Energy Mode circles use blue, yellow and purple for Automatic,
  Low Power and High Power, with thin outlines and readable inner symbols.
- Subtle neutral macOS hover highlights; the menu stays open during switching.
- Includes 0.2.0's compact icon, charging estimate and rated charger capability.

## Installation

With Homebrew already installed:

```sh
brew install --cask JonathanLee2020/inside-battery/inside-battery
```

For an existing Homebrew install, quit Inside Battery first:

```sh
brew update
brew upgrade --cask JonathanLee2020/inside-battery/inside-battery
```

Alternatively, download `InsideBattery-0.2.1-arm64.zip`, extract it, move the
complete `Inside Battery.app` to Applications and open it. Verify the archive
against `SHA256SUMS.txt`. Avoid running multiple app copies.

## Preview limits

This development archive is ad-hoc signed, not Developer ID signed or notarized.
Gatekeeper may prevent opening a downloaded copy. No quarantine bypass is supplied.
Homebrew uses our public tap, not an official Homebrew Cask listing. The local
MacPorts recipe has not been submitted to the official ports tree.

Power switching is optional and requires administrator approval. The development
Mac's original helper works with a temporary absolute-path launch, but normal
Service Management registration failed to resolve the bundle-relative executable.
Fresh-install approval, switching and restart persistence for this newly
source-built helper pair are unverified. The diagnostic recovery is not a public
installer. Do not treat this preview as a stable power-switching release.

The significant-energy list uses a private macOS 26.2 integration and may report
unavailable on other macOS versions or invalid responses. Charger capacity is a
charger rating, not live charging watts.

Verification: 171 executable self-checks, live energy query, UI rendering,
client/helper signature pinning, complete bundle verification, and ZIP extraction
round-trip. Fresh-install desktop testing and notarization remain outstanding.
