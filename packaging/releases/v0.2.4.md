# Inside Battery 0.2.4 — development preview

Apple Silicon (arm64), macOS 13 or newer. Intel binaries are not included.

## What's new

- New app icon: purple rounded tile with a green battery fill.
- Automatic now uses light purple.
- Low Power now uses warm lavender with a subtle gold tint.
- High Power now uses dark purple with white percentage text and a contrasting
  dark empty remainder, making partial charge easier to see.
- Selected Energy Mode circles match the menu-bar palette. Neutral hover and
  mode changes that keep the menu open remain intact.

## Updating

Sparkle-enabled versions (0.2.2 and newer) check the signed feed periodically.
With automatic checks enabled, this release is offered on their next check;
Inside Battery → Check for Updates… checks immediately. The standard dialog
shows these notes and offers Skip This Version, Remind Me Later and Install
Update. Installation replaces the app and relaunches it after user confirmation.
This is a compatible UI update only if the registered helper matches the archive.
Modified local helper pairs can still require manual installation.

0.2.1 and earlier need one manual or Homebrew upgrade to get Sparkle:

```sh
brew tap JonathanLee2020/inside-battery
brew install --cask JonathanLee2020/inside-battery/inside-battery
```

Existing Homebrew users can quit the app, run `brew update`, then
`brew upgrade --cask JonathanLee2020/inside-battery/inside-battery`.
Alternatively, extract the ZIP and move the complete app to Applications.

## Preview limits

This release is ad-hoc signed, not Developer ID signed or notarized. Gatekeeper
may block downloaded copies. Sparkle signatures do not replace Apple signing.
Fresh-install helper approval, switching, restart persistence and actual
package-manager installation remain unverified. Homebrew uses our own tap;
MacPorts remains a local recipe. Significant-energy integration is experimental
and enabled only on the inspected macOS 26.2 ABI.
