# Inside Battery 0.2.2 — development preview

Apple Silicon (arm64), macOS 13 or newer. Intel binaries are not included.

- Adds Sparkle's Check for Updates menu item and scheduled update checks.
- Standard update dialog shows the version and release notes, with Skip This
  Version, Remind Me Later and Install Update. Sparkle handles replacement and
  relaunch after the user chooses to install a compatible update.
- Updates and feeds use Ed25519 signatures; modified feeds are rejected and
  archives are verified before extraction. No silent automatic installation.
- An in-app update that changes a registered power helper is blocked with an
  explanation. Such changes need manual installation until helper upgrades are
  verified. UI-only updates retaining the helper can use Sparkle installation.

## Installation

0.2.1 and earlier have no updater. Install this version once manually or through
Homebrew to receive future compatible updates in the app:

```sh
brew tap JonathanLee2020/inside-battery
brew install --cask JonathanLee2020/inside-battery/inside-battery
```

For an existing Homebrew installation, quit the app, run `brew update`, then
`brew upgrade --cask JonathanLee2020/inside-battery/inside-battery`.
Alternatively, extract the versioned ZIP and move the complete app to Applications.
Avoid running multiple copies. The publisher must publish the signed feed along
with this release before updater-enabled copies are distributed.

## Preview limits

This development archive is ad-hoc signed, not Developer ID signed or notarized.
Gatekeeper may prevent opening a downloaded copy. No quarantine bypass is supplied.
Sparkle signing does not replace Apple signing or notarization.
Fresh-install power-helper approval, switching and restart persistence remain
unverified. A disposable app without a power helper passed the full download/install/relaunch flow through the standard Sparkle dialog.
Homebrew uses our own tap; MacPorts remains a local recipe only.

Verification: 177 executable checks, nested bundle/helper signatures, Sparkle
updater startup, signed archive/feed generation, real Sparkle feed download and
parsing, and rejection of a deliberately tampered feed. Current working local
app and helper were preserved during development.
