# Inside Battery 0.2.3 — development preview

Apple Silicon (arm64), macOS 13 or newer. Intel binaries are not included.

- Includes the current compact battery icons and native-style menu: lighter
  purple High Power progress, colored selection circles, neutral hover, and
  mode changes that keep the menu open without dimming.
- Includes charger rated capacity, optional time until fully charged, and the
  significant-energy parser fix for unnamed system coalitions.
- Includes Sparkle 2.10.0 from 0.2.2: Check for Updates, scheduled checks, version
  and release notes, Skip This Version, Remind Me Later, and Install Update.
  Compatible updates install and relaunch after user confirmation.
- Version metadata is 0.2.3/build 5. Documentation now matches the current app
  and clearly distinguishes verified checks from outstanding install testing.

This consolidates existing improvements; it does not change Sparkle behavior
from 0.2.2. Signed feeds/archives are required, silent installation is disabled,
and registered-helper changes are blocked until manual upgrades are verified.

## Installation

Download the ZIP, extract it, and move the complete app to Applications.
Versions 0.2.1 and earlier need one manual or Homebrew upgrade to get Sparkle.
Avoid running multiple copies.

```sh
brew tap JonathanLee2020/inside-battery
brew install --cask JonathanLee2020/inside-battery/inside-battery
```

For an existing Homebrew installation, quit the app, run `brew update`, then
`brew upgrade --cask JonathanLee2020/inside-battery/inside-battery`.

## Preview limits

This archive is ad-hoc signed, not Developer ID signed or notarized. macOS may
block a downloaded copy; the 0.2.2 Homebrew download was rejected by Gatekeeper.
Sparkle signatures do not replace Apple signing or notarization.
Fresh-install helper approval, power switching, restart persistence and actual
package-manager installation remain unverified. Significant-energy integration
is experimental and enabled only on the inspected macOS 26.2 ABI.

Previous verification: a disposable app without a power helper passed Sparkle
installation and automatic relaunch. The real updater parsed the public signed
feed, and a deliberately modified feed was rejected. Homebrew uses our own tap;
MacPorts remains a local recipe, not an official listing.
