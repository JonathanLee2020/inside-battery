# Inside Battery 0.2.9 — development preview

Apple Silicon (arm64), macOS 13 or newer. Intel binaries are not included.

## What's new

- Test Joey Automatic now uses the same darker grey border color as Yoshi,
  turtwig, Piplup, and Chimchar, replacing its lighter grey border.
- Test Joey retains its 1.75pt Automatic border and Joey purple fills, with
  High Power slightly darker. Low/High keep their gold/purple borders.
- Existing theme selections and the public power-helper pair are preserved.

## Updating

Sparkle-enabled releases (0.2.2 and newer) periodically check the signed feed.
With automatic checks enabled, compatible installations receive the update
window on their next check. Preferences → Check for Updates… checks immediately
(older versions call that submenu Inside Battery). Install Update replaces the
app and relaunches it after user confirmation. The public helper pair is retained;
modified local helper pairs may still require manual installation.

Versions before 0.2.2 need one manual or Homebrew upgrade to get Sparkle:

```sh
brew tap JonathanLee2020/inside-battery
brew install --cask JonathanLee2020/inside-battery/inside-battery
```

Existing Homebrew users can quit the app, run `brew update`, then
`brew upgrade --cask JonathanLee2020/inside-battery/inside-battery`.
Alternatively, extract the ZIP and move the complete app to Applications.

## Preview limits

This release is ad-hoc signed, not Developer ID signed or notarized. Gatekeeper
may block downloaded copies. Sparkle signing does not replace Apple signing.
Fresh-install helper approval, switching, restart persistence and actual
package-manager installation remain unverified. Homebrew uses our own tap;
MacPorts remains a local recipe. Significant-energy integration is experimental
and enabled only on the inspected macOS 26.2 ABI.
